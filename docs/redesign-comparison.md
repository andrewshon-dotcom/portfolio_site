# Redesign comparison

## Reference behavior

The reference uses a floating capsule navigation, a near-viewport editorial
hero, dramatic scale changes, long section pauses, rounded cards, three-column
work presentation, ambient background movement, subtle reveal animation, and a
strong two-column contact conclusion. Desktop layouts remain spacious through
1024px, tablet shifts work to two columns, and mobile becomes a single vertical
story with a compact menu.

## Existing portfolio weakness

The prior Andrew portfolio had a sound information architecture but relied on
notched controls, uniformly bordered cards, repeated grid treatments, a
literal dashboard-like illustration, and a visually dense résumé rhythm.
Only three selected projects reached public rendering because three records
were excluded by environment-dependent publication helpers.

## Changes implemented

- Replaced the header band with a floating frosted capsule and animated active
  state.
- Rebuilt the hero around larger line-controlled typography, layered commerce
  systems, pointer depth, ambient nodes, and moving data packets.
- Converted metrics into a flowing light ribbon and expertise into an
  asymmetric twelve-column bento.
- Reworked About into an editorial split with an original abstract identity
  panel and multi-column narrative.
- Removed the dotted résumé-style timeline in favor of generous editorial role
  entries and a sticky career summary.
- Published all six selected projects and created a stable three-by-two desktop
  grid, two-by-three tablet grid, and one-column mobile presentation.
- Rebuilt project cards with large color fields, layered system artwork,
  consistent card heights, modern tags, lift/focus responses, and moving data
  accents.
- Expanded every case study with challenge, contribution, technical solution,
  outcome, architecture, related work, and contact surfaces.
- Integrated the contact form into a translucent two-column finale and gave the
  footer a larger editorial closing gesture.
- Kept motion compositor-friendly through header arrival, hero line clipping,
  ambient system movement, pointer depth, data packets, and hover/focus states;
  all nonessential motion collapses under reduced-motion preferences.
- Added native below-the-fold rendering deferral for the long single-page
  narrative, preserving semantics and anchor access while reducing initial
  style and layout work.

## Final result

The finished site follows the reference's layout family, section rhythm,
floating navigation, project density, rounded surfaces, ambient movement, and
responsive progression while retaining Andrew's verified content, Manrope and
Inter typography, commerce-engineering focus, AS monogram, and original
navy/ivory/periwinkle/coral/mint/blue visual identity. No reference code,
illustrations, logos, screenshots, or proprietary assets were used.

## Refinement passes

### Pass 1 — composition

Adjusted hero line wrapping and column ratio, increased headline scale,
normalized the 1280px content rail, built the complete six-card grid, and
balanced desktop/tablet/mobile spacing.

### Pass 2 — motion and detail

Added header arrival, headline clipping, ambient system motion, pointer depth,
project hover/focus treatment, stronger contrast, credential copy interaction,
and reduced-motion fallbacks. A final performance pass removed expensive
scroll-timeline work and deferred off-screen section rendering, bringing the
standard desktop Lighthouse result to 93 performance and 100 in accessibility,
best practices, and SEO.
